# 上架清单

这次只准备源码。没有你的 AppID，没有真机会话，没有上传，也没有提审。下面每一项都要你用自己的小程序账号完成，完成前不能当作可以提交审核。

1. **AppID**  
   在微信公众平台注册小程序，把 `project.config.json` 的 `touristappid` 换成该账号的 AppID。不要把 AppSecret 写进仓库或小程序代码。

2. **HTTPS 接口域名**  
   自有服务器使用已备案域名和受信任的 HTTPS 证书，TLS 1.2 及以上。在「开发 - 开发设置 - 服务器域名」添加 request 合法域名，只填 `https://` 域名，不带路径和端口。说明见 [网络](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)。然后把同一域名写入 `miniprogram/config.js` 的 `apiBase`。  
   `trycloudflare` 临时地址只能在开发者工具里演示，不能作为正式接口或合法域名。上传前保持 `allowDemoTunnel` 为 `false`。

3. **主体、类目、备案**  
   小程序备案按 [备案操作指引](https://developers.weixin.qq.com/miniprogram/product/record/record_guidelines.html) 准备主体证件、负责人证件，并完成人脸核身和工信部短信核验。未备案不能发布。  
   类目对照 [小程序开放的服务类目](https://developers.weixin.qq.com/miniprogram/product/material/)（页面所载最后编辑 2026-11-03，提交时以后台要求为准）：非个人主体为「物流服务 - 查件 - 查件」，资质栏为「/」，范围是快递、物流查件；个人主体同样有「物流服务 - 查件」，并写明不包含寄件、收件。本程序只有查单号，没有寄件。

4. **隐私指引**  
   按 [隐私保护指引内容介绍](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html) 勾选「读取你的剪切板」。官方把 `wx.setClipboardData` 和 `wx.getClipboardData` 列在这一项。本程序只写入快递单号，不读取剪贴板。用途填写「把快递单号写入剪贴板，便于用户自行粘贴」。  
   另用自定义说明声明用户输入的手机号，用途「向自有服务器按完整号码查询已录入的订阅邮寄单号」。不要勾选位置、相册、麦克风、通讯录，也不要接微信手机号快速验证。弹窗接法见 [隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)。

5. **名称和商标**  
   界面标题使用《中国国家地理》和《博物》。这不表示官方客户端，小程序里也没有使用出版社标志。名称、简介和界面若使用这些刊名，需要你自行确认已获得相应授权，避免被认定为冒充官方。

6. **快递跳转**  
   三个按钮都调用 [wx.navigateToMiniProgram](https://developers.weixin.qq.com/miniprogram/dev/api/navigate/wx.navigateToMiniProgram.html)。没有核实到带单号的 path，所以 `path` 和 `extraData` 都是空的；有对应单号时先写入剪贴板。真机跳转还没验证，开发者工具不能代替真机。当前 `app.json` 不写已过时的 `navigateToMiniProgramAppIdList`。  
   韵达 `wxdeb5309aa3e93fd1`，来源是[韵达开放平台《微信小程序嵌入》](https://yundaex.apifox.cn/doc-345776)。中通 `wx7ddec43d9d27276a`，来源是[腾讯应用宝](https://sj.qq.com/appdetail/wx7ddec43d9d27276a)。中国邮政 EMS `wx63e410bc2c6a792e`，来源是[腾讯应用宝](https://sj.qq.com/appdetail/wx63e410bc2c6a792e)。

7. **上传**  
   只有你确认 AppID、域名、备案、类目、隐私指引和名称授权之后，才用自己的账号上传并提交审核。当前源码还不能当作已经具备提交条件。
