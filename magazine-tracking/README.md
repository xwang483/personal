# 刊邮

读者用**完整手机号**查询杂志邮寄单号的小网站。数据来自管理人员上传的 Excel 或 CSV，不连接任何快递公司。

知道完整手机号的人就能查到该号码下已导入的单号。这是明确的产品决定：不要求姓名、订单号或验证码。查询结果只包含杂志名称、寄出日期、邮寄方式和快递单号。

## 本地运行

需要 Node.js 22。

```bash
npm install
cp .env.example .env.local
```

在 `.env.local` 里填写 `ADMIN_USERNAME`、`ADMIN_PASSWORD` 和 `ADMIN_SESSION_SECRET` 后启动。会话密钥可以用 `openssl rand -base64 32` 生成。程序没有默认密码，也不会把密码写进页面或日志。

```bash
npm run dev
```

开发服务器默认是 [http://localhost:3000](http://localhost:3000)。读者页是 `/`，管理人员入口是 `/admin`。

```bash
npm test
npm run lint
```

## 第一次配置管理员

三个环境变量缺一不可，否则登录和上传都会拒绝，并提示尚未配置：

| 变量 | 要求 |
| --- | --- |
| `ADMIN_USERNAME` | 1 到 64 个字符 |
| `ADMIN_PASSWORD` | 至少 8 位，请自行使用长随机密码 |
| `ADMIN_SESSION_SECRET` | 至少 32 位，用来签名登录会话 |

修改密码后，旧的登录会话会失效。会话写在 `HttpOnly` cookie 里，大约 12 小时过期。生产环境请使用 HTTPS，cookie 会带 `Secure`。

## 表格格式

第一行必须是表头，列名要完全一致。空白间隔列可以留着，会被忽略。多出来的未知列也会忽略。缺少下面任一列表头时，整份文件会被拒绝：

`姓名`、`收货地址`、`邮寄方式`、`单号`、`日期`、`电话`、`杂志名称`、`订单号`

登录后可以下载空白模板和虚构示例（CSV 或 xlsx）。示例里的姓名、地址和单号都是虚构的，杂志名称带「示例」。姓名和收货地址**不会写入数据库**，也不会出现在查询结果里。示例手机号是 `13800001111`（两本杂志）和 `13900002222`（一本）。

支持：

- `.xlsx`（不要带宏，不要加密）
- UTF-8 CSV，可以带 BOM
- GB18030 CSV

限制：5MB，最多 1 万行数据，只读第一个工作表。

日期可以写成 `2026-03-02`、`2026/3/2`、`2026年3月2日`，或 Excel 日期。电话必须能规范成中国大陆 11 位手机号。`+86`、`86`、`0086`、空格、短横线和 Excel 末尾的 `.0` 都可以。只填一部分号码不会拿去搜索。

`电话`、`单号`、`订单号` 请在 Excel 里设为**文本**。超过可精确表示的整数范围（约 15 位以上）时，Excel 可能已经把末尾改掉。这种行会在校验里被拒绝，并说明精度损失无法恢复，不会把改坏的单号写进库。

## 导入

上传后先在服务器上校验。页面列出错误行，以及可通过记录的杂志、日期、邮寄方式和单号；手机号只显示掩码。确认之后才会写入。

重复导入是幂等的：

- 有订单号时，同一手机号、杂志名称和订单号视为同一条。日期、邮寄方式或单号有变化就更新
- 没有订单号时，同一手机号、杂志名称和单号视为同一条
- 完全相同的记录计为「未变化」，不会多出一行

没有删除界面。如果一条记录完全导错，需要先备份，再直接处理 SQLite 文件。

## 查询与隐私

读者先验证手机号。网站发送 6 位短信验证码，通过后写入一个约 30 分钟的 `HttpOnly` 签名 cookie。`POST /api/lookup` 只认这个会话里的号码，请求体里的手机号会被忽略。成功时只返回杂志名称、日期、邮寄方式和快递单号，不返回姓名、地址、手机号、订单号，也不返回别人的记录。

验证码在库里只存哈希，大约 5 分钟过期，用过即废，每个码最多试 5 次。同一号码 60 秒内不能重发，并且按号码和来源地址限制发送次数。

短信走一个很小的发送接口。默认 `SMS_PROVIDER=console`，把验证码打在服务器日志里，只给本机调试。生产环境必须改成 `aliyun`，否则发送会拒绝。选阿里云是因为它的「发送短信」就是一次请求：签名、模板、变量 `code`，不需要再装 SDK。上线前要在阿里云短信服务申请**短信签名**和**验证码模板**（模板里的变量名是 `code`），审核通过后填写：

| 变量 | 作用 |
| --- | --- |
| `SMS_PROVIDER` | `console` 或 `aliyun` |
| `ALIYUN_SMS_ACCESS_KEY_ID` | 阿里云 AccessKey |
| `ALIYUN_SMS_ACCESS_KEY_SECRET` | 阿里云 AccessKey Secret |
| `ALIYUN_SMS_SIGN_NAME` | 已审核的签名 |
| `ALIYUN_SMS_TEMPLATE_CODE` | 已审核的模板 CODE |
| `WECHAT_APP_ID` | 小程序 AppID，给微信手机号组件用 |
| `WECHAT_APP_SECRET` | 小程序 AppSecret，只放在服务器上 |

小程序优先用按钮 `open-type="getPhoneNumber"`。服务器拿一次性 code 调微信 `phonenumber.getPhoneNumber`，由服务器决定号码。这个能力要求已认证的**非个人主体**，并且按调用次数计费。没有开通时，小程序改用同一套短信验证码。

这里不拉取物流轨迹，也没有到达预估。韵达、中通和中国邮政 EMS 可以另开官方页面，见下一节。

默认每个来源 10 分钟最多查询 20 次，登录尝试 15 分钟最多 8 次。没有公开的批量导出。服务器日志不记录手机号、姓名、地址、密码或文件内容。

限流计数存在进程内存里，重启后清零。站点放在反向代理后面时，设置 `TRUST_PROXY=1`，否则所有访客会共用一个计数。不设这个值时，程序不信任 `X-Forwarded-For`。

## 跳转到快递公司查询页

读者结果里的「查询物流」只认识韵达、中通和中国邮政 EMS。匹配的是「邮寄方式」的别名，不是单号本身，也不会把表格里的任意文字当成网址。

2026-11-13 核对过的官方页面：

| 快递 | 打开的地址 | 说明 |
| --- | --- | --- |
| 韵达 | https://web.yundaex.com/Home | 「运单号查询」表单。`https://www.yundaex.com/cn/trackResult?mailNo=` 返回 404，没有采用 |
| 中通 | https://www.zto.com/check | 「运单查询」表单，看不到可用的单号参数 |
| 中国邮政 EMS | https://www.ems.com.cn/ | 北京市政务服务网写明的快递物流官网（http://www.ems.com.cn）。没有核实到可自动填入单号的参数 |

这三个地址都不会把单号拼进链接，也不会声称页面会自动填入。

别名（忽略大小写和空格）：

- 韵达、韵达快递、韵达速递、YUNDA、YUNDAEX
- 中通、中通快递、中通速递、ZTO
- EMS、中国邮政、邮政 EMS、邮政快递、邮政快递包裹、中国邮政速递

点击「查询物流」会在这次点击里先同步复制单号，再打开上表中的固定地址。复制失败时仍打开页面，并提示需要手动输入。链接只带快递公司自己的地址，不附带手机号、姓名或地址。

顺丰、京东以及其他写不上表的邮寄方式没有外链，只保留复制，并说明暂不能跳转。

## 存储和部署

数据在单个 SQLite 文件，默认是 `data/shipments.sqlite`。这是单实例方案：只运行一个写入进程，并把 `data/` 挂到持久卷。没有持久盘时，导入的数据会在实例更换后丢失。不要同时跑多个写入进程。

备份时复制主库和旁边的 `-wal` 文件，或先做 checkpoint。不要把 `data/` 和 `.env.local` 提交到仓库。

```bash
npm run build
npm start
```

本仓库按草稿保存，没有做公开部署。

## 微信小程序

读者用的原生小程序在 `miniprogram/`。表格导入仍只在网站的 `/admin`，小程序里没有上传入口。

「复制单号」只写入剪贴板，不会接着跳转。另外有三个按钮：韵达、中通、中国邮政 EMS。点它们会调用 `wx.navigateToMiniProgram`。三家都没有核实到可带单号的页面路径，所以 `path` 为空、`extraData` 为空；如果当前结果里有这家快递的单号，会先 `wx.setClipboardData` 再跳转，并提示粘贴。

`npm test` 里的小程序用例是 Node 模拟，不是微信开发者工具编译，也不是真机跳转。开发者工具不能代替手机上的真实跳转。上架步骤见 `miniprogram/上架清单.md`。`project.config.json` 里的 `touristappid` 只是占位，还不能提交审核。

## 运行网站、打开小程序、提交发布

网站需要 Node.js 22。在 `magazine-tracking/` 执行 `npm install`，复制 `.env.example` 为 `.env.local` 并填写三个管理员变量，然后 `npm run dev`。读者页是 http://localhost:3000 ，导入入口是 `/admin`。

小程序用微信开发者工具导入 `magazine-tracking/miniprogram` 目录，基础库 3.5.5 或更新版本。现在的 AppID 是 `touristappid`，只能本地预览。发布前要自己做完这些事：在微信公众平台注册小程序，把 `project.config.json` 的 `appid` 换成该账号的 AppID，在 `config.js` 填写已备案的 `https://` 接口域名，并在小程序后台把同一域名加入 request 合法域名。查询会请求 `POST /api/lookup`。没有调用接口地址时，查询页会提示还不能查询，三个快递跳转按钮仍然可以点。确认类目、备案和隐私指引后，再用自己的账号上传并提交审核。细节见 `miniprogram/上架清单.md`。
